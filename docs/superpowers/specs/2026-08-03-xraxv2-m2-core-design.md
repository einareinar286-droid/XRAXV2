# XRAXV2 M2 核心功能设计（Mock）

## 目标

在不接入真实账号、云端附件或真实人员数据的前提下，完成可演示、可测试的角色权限、隐患闭环与履职考核主流程。

## 已确认规则

- 角色：超级管理员、安全监察部、市场营销部、员工；不设置高管角色。
- 隐患：全员可随手拍上报；定位为可选；仅安全监察部/超级管理员可交办市场营销部；市场整改后必须返还安全监察确认闭环。
- 履职：只有“按时提交且审核通过”计为完成；履职率必须达到 100%；未提交、待审核、退回、逾期提交均进入考核；本期无任务显示“不适用”且不进入分母。
- 权限：员工仅提交本人履职；安全监察部、市场营销部仅审核本部门履职；超级管理员可跨部门管理。非超级管理员不得改写他人的原始提交内容。
- 附件：校验 Word、Excel、文本、图片、PDF 的元数据；本期不上传真实文件到公网或云端。

## 边界

- 所有人员、隐患、履职任务均为匿名 Mock 数据；不导入参考表中的滞后数据。
- 不含真实手机号登录、密码记住、微信登录、短信、AppID、Cloudflare/火山引擎部署或私有云对象存储。
- 超级管理员的真实身份映射只允许未来通过本机忽略配置注入，禁止写入仓库。

## 验收

1. 员工可无定位上报隐患，不能交办、整改或复核。
2. 安全监察部可处理任一部门上报的隐患；市场营销部只能处理受办整改；安全确认后才闭环。
3. 履职仪表盘明确显示履职率、应履职、按时通过、考核项、部门明细、待审核项。
4. 审核人可在本部门范围内通过或退回履职；退回必须填写原因。
5. 单元测试、H5、微信小程序构建通过。
