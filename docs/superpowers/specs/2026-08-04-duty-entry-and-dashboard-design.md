# 安全履职入口与仪表盘权限设计

## 目标

将全员个人安全履职填报与全员履职管理看板分为两个独立入口，避免将日常填报误认为管理权限。

## 范围

- 所有角色可从左侧进入“安全履职”，查看并填写本人任务。
- 仅超级管理员与安全监察部可见“履职仪表盘”，用于查看全员汇总、明细、待审核和考核清单。
- 超级管理员仍可从“安全履职”填写自己的履职；仅超级管理员可审核或改写他人记录。
- 市场营销部与普通员工不显示仪表盘、隐患交办或操作日志入口。

## 导航

- 超级管理员/安全监察部：工作台 → 隐患交办 → 安全履职 → 履职仪表盘 → 随手拍 → 送气工画像（规划中）→ 我的。
- 市场营销部/普通员工：工作台 → 安全履职 → 随手拍 → 送气工画像（规划中）→ 我的。

## 验收

- 每个角色都能看到“安全履职”并进入既有个人任务页。
- 仅超级管理员和安全监察部能看到“履职仪表盘”且可进入全员看板。
- 左侧导航顺序与本设计一致；不改变小程序底部 Tab。
- Mock 数据边界不变，不导入或上传真实人员、履职、附件或隐患数据。
