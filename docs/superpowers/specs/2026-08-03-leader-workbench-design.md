# XRAXV2 领导工作台与自适应导航设计

## 目标

在不伪造真实经营数据、不开启真实登录和不接入外部资讯的前提下，将首页升级为领导可快速浏览的安全工作台，并让 H5 电脑端使用左侧导航、手机端保留底部导航。

## 范围

### 1. 自适应导航

- 电脑网页（宽度不小于 1200px）：固定左侧导航，顺序为工作台、履职、随手拍、我的。
- 手机/微信小程序：保留底部导航，顺序同步为工作台、履职、随手拍、我的。
- 现有页面路由保持不变，禁止复制两套业务页面。

### 2. 领导工作台

首页按下列顺序呈现：

1. 数据状态：明确写出“演示数据”或“尚未接入真实业务数据”，并显示统计时间。
2. 闭环总览：隐患总数、待交办、待整改、待复核、已闭环、重大隐患。
3. 履职总览：履职率、待审核、考核项；履职率只有 100% 才显示达标。
4. 重点待办：按重大、临期、待复核优先级展示当前角色可处理事项。
5. 快捷入口：仅展示当前角色有权限的上报、交办、审核、履职入口。

视觉采用现有深矿物绿工作台体系；“高级感”来自清晰层级、状态轨和数据密度，不以模拟仪表数字冒充真实业务数据。

### 3. Mock 身份入口

- Cloudflare 测试站：不提供普通员工可见的身份切换入口；当前站只作为匿名 Mock 界面与流程演示，不宣称安全鉴权。
- 本地开发：通过未提交的本机配置开启 Mock 角色切换，用于流程测试。
- 真实账号上线前：角色由后端会话决定；超级管理员的跨部门权限通过服务端绑定，不用前端隐藏按钮替代。

## 明确不做

- 不清空现有未提交的随手拍草稿。
- 不接入全球燃气/生产安全实时资讯；该功能在系统上线后独立实现为 Cloudflare Worker 受控资讯服务。
- 不导入真实人员、履职、隐患、手机号或附件。
- 不实现真实登录、手机号密码、微信登录或权限后台。

## 数据与错误处理

- 当前 Mock 聚合数据必须标注演示属性；没有可用数据时显示“暂无真实业务数据”，不显示虚构百分比或今日结论。
- 聚合服务读取失败时，工作台保留可用区块并在对应区块说明“数据加载失败，可下拉重试”。
- 统计时限统一使用页面加载时间，仪表盘与列表使用同一份查询结果，避免同屏数字矛盾。

## 验收标准

1. H5 宽屏出现左侧导航，手机与小程序仍是底部导航；四个入口顺序一致。
2. 首页可一眼识别数据状态、六项闭环指标、三项履职指标和重点待办。
3. 所有 Mock 数字明确标为演示数据；无真实数据场景不输出假设业务结论。
4. Cloudflare 构建不展示身份切换入口；本地配置缺失时也不展示。
5. 现有测试、H5 构建、微信小程序构建通过。

## 潜在风险分析

- 高：静态 Mock 无法识别真实超级管理员。应对：线上隐藏身份切换；真实账号上线后由服务端鉴权。
- 中：不同区块分别请求数据会产生不一致。应对：定义统一工作台快照服务，一次读取生成同屏指标与待办。
- 中：领导将演示数字误读为真实经营情况。应对：固定数据状态条，未接入真实数据时禁止使用“今日完成率”等业务结论。
- 低：桌面侧栏影响小程序布局。应对：仅在 H5 宽屏启用，移动端沿用既有 TabBar。
