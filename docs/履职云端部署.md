# 安全履职云端启用说明

本次已把 V1 表中的核心字段落为数据模型：人员、部门/站点、岗位履职动作、频率、实际周期、截止日、填报说明、照片、抽查与审计。原始 Excel 不会被打包进小程序。

## 一次性启用步骤

1. 在 HBuilderX 打开 `D:\xrax`，右键 `uniCloud-aliyun`，关联一个公司名下的阿里云服务空间。
2. 从插件市场导入官方 `uni-id-pages` 和 `uni-id-common`；采用用户名密码登录，管理员账号赋予角色 `SAFETY_ADMIN`，普通员工不授予该角色。
3. 上传 `database` 下的四个 schema，并上传云对象 `duty-service`；在云函数中通过“管理公共模块依赖”绑定 `uni-id-common`。
4. 将履职表中的每一条“人员 - 动作”关系导入 `xr-duty-assignments`，并用对应 `uni-id-users._id` 填写 `ownerUid`。首次生效日期填实际起始日，不能用演示日期替代。
5. 在云端控制台确认定时任务每日运行；首次运行会补齐从生效日起缺失的周期实例。云端代码已按中国自然日计算周期与逾期状态。

## 权限边界

- 普通员工：云对象 `myInstances` 仅按 token 中的 `uid` 查询；`submitInstance` 会再次校验实例属主。
- 安全监察管理员：只有 token 带 `SAFETY_ADMIN` 才可调用 `adminInstances`。
- 删除：前端没有删除入口，schema 禁止客户端删除，云对象也不提供删除方法。
- 附件：正式启用时上传到 uniCloud 存储，并配置为登录用户才能读取；不要把现场照片放到公开链接。

## 当前演示与生产的区别

履职页面在未关联服务空间前使用匿名演示任务，便于查看界面。关联云空间并配置 `uni-id` 后，前端会自动调用 `duty-service`，真实周期、照片和历史记录存入云端数据库。
