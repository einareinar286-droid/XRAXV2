# 徐燃安巡验收用例与追溯矩阵

**文档编号：** SPEC-TEST-001
**状态：** 用例可执行；当前结果均为阻塞/待证
**证据原则：** 测试输出、受控请求记录、审计结果、构建日志、截图/录屏和真机测量均须能定位到版本、环境、时间和执行人。

## 1. 验收用例

| 编号 | 场景 | 前置条件 | 步骤 | 预期结果 | 证据类型 | 初始结论 |
| --- | --- | --- | --- | --- | --- | --- |
| UC-01 | 正向闭环 | 安全角色、市场受办人、可用测试隐患与附件 | 安全上报→交办；市场提交整改；安全复核闭环 | 状态依次为 `REPORTED`、`ASSIGNED`、`RECTIFICATION_SUBMITTED`、`CLOSED`；每步版本递增并追加审计 | 自动化/集成输出、审计记录、操作录屏 | 部分通过：Mock 测试 5/5 含正向闭环；真实后端、附件与界面路径阻塞/待证 |
| UC-02 | 角色越权 | `EXECUTIVE_READONLY` 有合法 token | 调用上报、交办、整改、复核任一写接口 | 服务端返回 `ACCESS_DENIED`；无状态和审计写入 | 服务端测试输出、审计查询 | 阻塞/待证 |
| UC-03 | 部门越权 | 市场角色 token；目标隐患未交办给本人/本部门 | 提交整改、读取详情或尝试下载附件 | 服务端返回 `SCOPE_DENIED`；不泄露隐患或附件数据 | 服务端测试输出、响应脱敏检查 | 部分通过：Mock 覆盖市场部受办前读取拒绝；token、跨部门和附件场景阻塞/待证 |
| UC-04 | 伪造角色/部门 | 普通角色 token；篡改请求体中的 role、department、actor | 请求受限写接口 | 服务端以 token 与实体记录重算身份，返回 `ACCESS_DENIED` 或 `SCOPE_DENIED` | 抓包/集成测试、服务端日志摘要 | 阻塞/待证 |
| UC-05 | 跨状态跳转 | 任意合法账号；隐患处于 `REPORTED` 或 `ASSIGNED` | 直接请求闭环/退回等不允许操作 | 返回 `STATE_CONFLICT`；状态、版本和审计不变化 | 单元/集成测试输出 | 阻塞/待证 |

| UC-07 | 闭环后修改 | 隐患已 `CLOSED`；普通用户与管理员账号 | 普通用户尝试编辑/整改；管理员无制度依据重开；管理员有依据重开 | 普通用户返回 `STATE_CONFLICT`/`ACCESS_DENIED`；无依据重开被校验拒绝；有依据重开留痕 | 集成测试、审计记录 | 阻塞/待证 |
| UC-08 | 附件越权 | 私有附件已绑定隐患；无权限用户、受权用户 | 分别请求下载或预览同一附件 | 无权限返回 `ATTACHMENT_DENIED`；受权用户获得短时受控访问；不出现长期公开 URL | 下载授权记录、响应检查 | 阻塞/待证 |
| UC-09 | 网络失败与恢复 | 可控超时/断网环境；表单已填写 | 上报、整改或复核提交时断网，恢复后重试 | 显示可理解失败与重试；不重复写入；重试遵守幂等与版本规则 | 网络模拟记录、界面录屏、审计查询 | 阻塞/待证 |
| UC-10 | 空态 | 角色范围内无隐患；另备无权限样本 | 进入待办、详情或统计入口 | 明确显示空数据；不把空数据与无权限/网络失败混淆 | 截图/组件测试 | 阻塞/待证 |
| UC-11 | 加载态 | 控制接口延迟；有正常响应与错误响应 | 打开列表、详情、图片区域 | 显示骨架或加载提示；无白屏；加载结束切换正确 | 录屏、性能面板或组件测试 | 阻塞/待证 |
| UC-12 | 真机动画帧率 | 微信开发者工具、至少一台真机、代表性数据与图片 | 执行 Tab 切换、待办→详情、上报→详情、整改→待复核、复核→闭环、长列表滚动 | 内容转场 180–300 ms；只动画允许属性；真机目标 60 FPS，无可感知卡顿/白屏；未达标有降级记录 | 开发者工具记录、真机设备记录、录屏 | 阻塞/待证 |
| UC-13 | 履职回归 | 现有履职工程、管理员账号、构建环境 | 执行履职页面关键路径、`SAFETY_ADMIN` 查询和微信小程序构建 | 既有履职功能、管理员查询和构建均不回归 | 回归清单、构建日志、测试输出 | 阻塞/待证 |

## 2. 用例执行记录模板

每次执行 UC 用例时，在对应测试报告或开发日志中至少记录：

| 字段 | 内容 |
| --- | --- |
| 用例编号 | 如 `UC-06` |
| 版本 | Git 提交、构建号、服务端版本 |
| 环境 | Mock/测试/预发布，设备、网络和测试数据标识 |
| 执行人和时间 | 可追溯责任人及时间 |
| 输入与步骤 | 与用例一致的最小可复现输入；不得保存 token 或敏感附件 URL |
| 实际结果 | 状态、错误码、版本、审计或界面行为摘要 |
| 证据位置 | 测试输出、截图、录屏、审计记录或构建日志链接/路径 |
| 结论 | 通过、不通过或阻塞 |
| 缺陷/处置 | 缺陷编号、修复版本、风险接受记录或补证计划 |
