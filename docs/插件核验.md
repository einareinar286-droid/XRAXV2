# 跨端方案与插件核验

| 能力 | 采用方案 | 来源与维护 | 目标平台 | 结论 |
| --- | --- | --- | --- | --- |
| 项目框架 | uni-app Vue 3 | DCloud 官方主流框架 | 微信小程序、H5、Android、iOS | 使用 |
| 通用界面组件 | uni-ui（按需导入） | DCloud 官方；插件市场持续更新 | 小程序、H5、App | 使用 |
| 图片选择 | `uni.chooseImage` | uni-app 官方 API | 微信小程序、H5、App | 使用 |
| 文件上传 | `uni.uploadFile`/uni-file-picker | uni-app 官方 API / DCloud 官方组件 | 小程序、H5、App | 生产版接 uniCloud 存储 |
| 当前定位 | `uni.getLocation` | uni-app 官方 API | 微信小程序、H5、Android、iOS | 使用，需授权 |
| 地图选点 | `uni.chooseLocation` | uni-app 官方 API | 微信小程序、H5、Android、iOS | 使用，生产版配置地图 Key 与安全网络 |
| 小程序提醒 | 微信订阅消息 `uni.requestSubscribeMessage` | uni-app 官方封装、微信模板配置 | 微信小程序 | 二期，需用户订阅 |
| App/在线提醒 | uni-push 2.0 | DCloud 官方 | App、Web、小程序在线态 | 二期 |
| Windows | 响应式 H5 + Electron 打包 | uni-app 官方宽屏/Electron 路径 | Windows | 后续适配；不放入小程序首验收 |

## 明确不使用

- 不采用来路不明的地图、拍照或推送原生插件。
- 演示版关闭 uni 统计，避免额外采集页面与设备统计数据。
- 不在小程序保存 AI Key、地图服务私钥或企业通知密钥；所有敏感调用由云函数或公司后端执行。
- 送气工画像现有静态 HTML 不直接嵌入小程序，后续迁移其分级配置、导入字段和聚合报表。

## 原生能力标注

`getLocation`、`chooseLocation`、相机/相册选择都需要各端的用户授权；App 发布时还需在 manifest 中声明定位权限。其余核心闭环页面仅使用跨端通用 Vue 与 uni-app API。
